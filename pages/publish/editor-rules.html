详细提交页 视觉规则页

本页把 editor.html / editor.css 已落地的视觉约定固化为可交互规则：令牌、几何、布局、组件正反例、全状态与动效。所有色值逐字取自 css/app.css 的 :root 与 [data-theme="dark"]，不臆造、不改源文件。

主操作 = 暖墨：--action → --action-deep 渐变 + --on-action 白字（暗态翻转为暖象牙白 + 深字）。
古铜金四档只做签名：徽章 / 选中态 / 品牌签名，不作主按钮底（V3.4 刻意解耦）。
功能色：blue 信息 / success 成功 / warning 警示 / error 错误，各配 soft 浅底；文字 5 级分层。
暗色自动适配：切换 data-theme=dark 后全部令牌由 app.css 自动翻转，不写单元素暗色补丁。
角色色约定（本页特有）：供应方向在 editor.css:5 把 --primary 重映射为 --success 绿（亮 #2B6B4F / 暗 #52B788）；需求方向保持金。选中 / 激活 / 步骤圆点 / chip 跟随当前角色色。用顶栏「需求·金 / 供应·绿」切换可实时预览。

布局 · 390×844 基准

以 390×844 移动端 H5 为第一基准，桌面加宽但不破；无页面级横向溢出（scrollWidth == clientWidth）。

详细提交 · 步骤示意
基准视口 390×844（--phone-w / --phone-h）；可点目标 ≥44×44px。
页面统一水平边距 16px（--page-pad）：整行卡片 / 标题 / 按钮与屏幕边缘统一 16px。
底部固定操作栏 86px（--actionbar-height = 58 本体 + 14×2 间距），悬浮于页面底色之上，栏体自身不带背景色 / 分隔线 / 阴影。
正文滚动预留 120px（--actionbar-reserve），避免末行内容被固定操作栏遮挡。
本页卡片采用值（已登记，非 A2 的 14）：圆角 16px / 内距 15px，属有意覆盖，登记见第 06 节，不回退以免全页位移。

4.1 按钮

主操作（下一步 / 提交）= 暖墨渐变；品牌金只用于选中 / 徽章 / 签名，禁止拿金当主按钮底。

正确
禁用（opacity .5） 加载中
墨主操作：linear-gradient(180deg,--action,--action-deep) + --on-action 字；幽灵=玻璃浅底 + 发丝边；危险=红浅底 / 红字 / 红边；禁用 opacity:.5;cursor:not-allowed；加载态用旋转环替换文字。
暗态动作色翻转：--action #EBE4D6 → --action-deep #D3C9B6，字 --on-action #1A1611（暖象牙白 + 深字，同一套非金即墨逻辑）。
错误反例
拿金渐变当主按钮底
禁止：把品牌金渐变（--primary-strong→--primary-dim）铺满主操作面。金在米白底边界模糊、小字对比不足；V3.4 已刻意把主操作解耦为暖墨。金只留在徽章 / 选中态 / 品牌签名。

4.2 chip 多选胶囊

选中 = 浅底软态，不用实色填充白字；跟随供应绿 / 需求金角色色。点击下方胶囊可切换选中。

正确 · 软态选中
选中：--primary-soft 浅底 + --primary-dim 深字 + 1px --accent-line 描边 + 600 字重；未选=白底细边 text-2；禁用 opacity .5。供应方向整体翻绿。
错误 · 实色填充白字
实色渐变 + 白字（禁）
禁止：选中态用 linear-gradient(135deg,--primary,--primary-dim) 实底 + 白字。与全页「浅底深字」的软态选中语言不统一，供应绿下更显突兀。

4.3 表单字段 / 选择器 / 错误态

label 12/600；必填红星 --danger；占位 text-3；hint 11px（亮态加深到 text-2 达 AA）；focus 金描边 + focus 环；error 红边 + 3px 红环。

正确 · 可见控件镜像错误态
请填写信息标题（必填）
请选择所属类目
select 与 PickX 触发钮都要镜像：原生 select.error 与可见触发钮同时红边 var(--error) + 3px var(--error-soft) 环；带错获焦保持红环，不被 focus 金边顶替。只读=透明底 / 无边框 / text-2。
错误 · 只红隐藏原生控件
禁止：校验只给 opacity:0 的原生 select 加红边红环，可见触发钮保持中性——错误态用户不可见。错误必须落在可见控件上。
