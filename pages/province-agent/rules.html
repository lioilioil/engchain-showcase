本页为省级总代体系运营规则梳理（demo 演示口径）：模拟测算 · 非税务意见，不构成合同、付款、开票或税务依据。合同条款以 O4《二级合作协议》为准；税务口径见税务说明页。
招募资格与名额 企业主体同省名额
主主体资格
仅限依法登记的企业公司主体（自然人禁入）；主体信息须与营业执照一致，统一社会信用代码唯一绑定——一公司只能绑定一家省级总代。
省同省锁定
二级公司须与省级总代属同一省份；跨省申请会被系统拒绝。
额名额机制
各省二级名额 = max(10, 该省地级市数量)；pending / approved / suspended 均占名额；terminated / removed / rejected 释放名额。
独一人一省 / 省独家
一个省级总代独家负责一个授权省；在册（active/suspended）总代占位，终止/撤销后该省可重新授权。

签约流程（O4《二级合作协议》八条摘要） 电子签双轨
双轨并存：路径① 总代发起 → 平台终审 → 二级签署；路径② 招商码 → 企业自助申请 → 总代初审 → 平台终审 → 自动发起 O4 → 二级签署。两条路径最终都落到同一份 O4 协议。
八条条款（demo 文本，生产由律师定稿）：
条款内容
① 合作主体与授权甲方省级独家总代，乙方本省二级合作分代理商；以营业执照载明信息为准。
② 授权范围与独家边界不跨省、不发展下级、不以甲方名义对外承诺独家权益。
③ 分账测算口径约定所得 = 自身真实消费实付 × 50% 总盘 × 约定比例（0–50%），仅内部测算，平台不付款、不开票。
④ 冻结与退款消费 T+7 冻结；冻结期退款剔除；出冻结退款先冲当月红字、不足转次月；特殊退款按流水号等额冲减。
⑤ 双方权利义务甲方提供本省渠道支持与台账；乙方真实履约、如实申报，不得刷单、拉人头、收取入门费。
⑥ 保密条款商业数据、分账测算与用户信息保密，终止后保密义务延续。
⑦ 解除与终止违约经通知未改正可解除；解除后名额与绑定释放，台账封存只读，已发生测算不追溯付款。
⑧ 争议解决与生效协商不成提交甲方所在地有管辖权法院；双方签署后生效，电子存证与纸质签署具同等展示效力。

合规边界细则
省级总代 / 二级均不得跨省经营、不得发展下级代理、不得拉人头、不得收取入门费、不得承诺收益。
内部测算：分账为内部测算：平台零支出、不付款、不开票；演示口径与返佣佣金体系（Referral 键）数据域隔离，两套体系互不写入。
收入来源同源声明：总代 / 二级的收入来源与原企业合伙人、个人合伙人一致——均基于邀请他人入驻平台后，被邀请人产生的消费效果向上级邀请方支付分佣（原体系）或计算分佣数据（省代体系）；差异仅在层级 / 比例 / 结算形态。
税务口径（法定预扣 / 企业税目 / 代扣边界）详见税务说明页，两页语义分区互不替代。

FAQ（常见问题） 10 条
1. 如何成为二级合作公司？
两种路径：路径① 由省级总代直接发起邀请，经平台终审后签署 O4 开通；路径② 持省级总代的招商码在线提交企业申请，经「总代初审 + 平台终审」双级审批后自动发起 O4，签署即开通。两条路径殊途同归，均为同一份协议。
2. 约定比例如何确定？
由总代与二级协商，范围 0–50%（含两端），须经双级审批；每次变更写入 ratioLog 留痕，自审批通过时点生效，不追溯已发生台账。
3. 为什么「约定所得」不可提现？
省代体系与原返佣体系本质不同：返佣是平台真付钱（增量佣金）；省代体系的约定所得只是内部测算数字，平台零支出、不付款、不开票，因此不产生可提现余额，仅作经营对账与决策参考。
4. 消费冻结如何结算？
合格消费 T+7 冻结，冻结期满自动结算计入约定所得；冻结期内退款直接剔除（不计入基数）。出冻结后退款按「当月红字 → 不足转次月」规则冲减，特殊退款按指定流水号等额冲减对应笔。
5. 终止 / 解除后台账如何处理？
台账封存只读（数据保留可审计），不再产生新测算；名额与省绑定同步释放，可重新授权他人；已发生测算不追溯付款。
6. 哪些消费计入测算基数？
仅计入真实消费类目（订单实付 / 积分解锁实付 / 增值服务实付）；充值、赠送积分、入驻费、退款冲减不计入基数。
7. 省级总代与个人合伙人的收入来源有区别吗？
来源同源：都靠邀请他人入驻平台，被邀请人产生的消费效果向上级邀请方支付分佣（原体系）或计算分佣数据（省代体系）。区别只在层级、比例与结算形态（平台真付钱 vs 平台零支出内部测算）。
8. 我的比例变更会影响历史账单吗？
不影响。比例变更自审批通过时点生效，仅影响之后的消费；历史台账按原约定比例测算，不追溯不重算。
9. 企业主体的税务如何处理？
企业取得代理 / 分销收入自行申报增值税与企业所得税；平台不经手企业收益、不向企业付款，对企业主体无代扣义务。个人合伙人返佣若平台实付，才按劳务报酬预扣预缴。详见税务说明页。
10. 省代数据与返佣数据会互相串吗？
不会。两套体系使用独立数据键（省代体系 engchain-agent-* / 返佣体系 Referral 键）完全隔离；二级申请、招商码均不写入 Referral 键，互不污染。
