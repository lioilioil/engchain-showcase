发布编辑器 · 信息获取目标 → 设计原则 → 落地改动 映射

先定"要获取什么、为什么"，再定"用户怎么填最顺"，最后落到布局/交互/动效改动——每个改动都能追溯到目标和原则。
① 执行目标 · 要获取什么
三类信息，各自决定一个业务环节
匹配信息决定"能不能对上"标题 · 品类 · 区域 · 价格 · 描述 · 建企买卖四要素 → 列表卡片展示 + AI 匹配度计算 + 供需对接
信任信息决定"敢不敢联系"实名 · 企业名 · 联系方式 · 押金/免费额度 → 过滤垃圾信息、建立交易信任
经营信息决定"平台怎么变现/治理"有效期 · 联系方式解锁 · 接受议价 · 审核材料 → 免费额度消耗、押金冻结、审核通过率
关键结论不同品类信息密度差异极大材料/设备需求 5–7 字段即可撮合；建企买卖需 15+ 字段（重表单）；招聘约 8 字段。▶ 表单密度必须品类驱动，不能一套密度走到底
② 设计原则 · 用户怎么填最顺
优秀操作感受 = 可预期 · 掌控 · 低摩擦 · 有反馈 · 无恐惧
可预期填之前知道要填什么单屏决策点 ≤5（认知负荷 4–7）；章节预告；按钮文案带后果
有掌控随时保存 · 回退 · 预览数据不丢；进度始终可见；动作可逆（草稿/撤回）
低摩擦能选不填 · 能预填不输智能默认值；选项化；AI 辅助可撤销；格式即时防错
有反馈每项完成有轻反馈进度可视化；错误就近、具体、可行动（24% 用户因意外字段/报错放弃）
无恐惧成本与隐私前置透明19% 用户因"数据用途不明"放弃——钱和联系方式可见性提前说明
专业引导不打扰的引导章节预告 → 品类后置清单 → 字段即解释 → 成本/隐私前置。引导只在"决策点"出现
③ 落地改动 · 布局/交互/动效
每条都能追溯到原则与目标
布局 L1合成进度头（置顶）→ 可预期 + 有掌控：始终知道在第几步
布局 L2AI 降级一行胶囊→ 低摩擦：可选项不抢首屏
布局 L3章节面板 + 密度品类化→ 可预期：轻品类折叠选填，重品类全展开
布局 L4操作栏固定三槽→ 有掌控：按钮位置不跳
布局 L5成本双时机（选品类轻提示 / 提交前明细）→ 无恐惧
交互 I1–I6切品类反馈 / 失焦校验 / AI 撤销 / 图片闭环 / 隐私锁引导 / 草稿保护→ 低摩擦 + 无恐惧 + 专业引导
动效 M1–M4入场编排 / 步骤方向 / 完成度满格 / 成功里程碑→ 有反馈 + 完成动机（Fogg：能力×触发）
