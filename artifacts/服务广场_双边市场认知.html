服务广场 · 双边市场深度认知

先分清"谁在用、在什么场景用、为了什么目的"，再谈打磨——每个改动都要能回答"为哪一方解决什么问题"。
① 用户（买方 · 被服务者）
建设/施工/材料企业主、项目经理、采购负责人。不是服务从业者，是"遇到工程问题来找解决方案"的人。
核心场景
S1 应急投标截止前要保函/资质——搜+比+快下单，高紧迫
S2 刚需资质到期/升级、安许新办——找专业代办，计划性
S3 比价造价咨询/结算审核——多机构比价，价格敏感
S4 履约下单后跟踪进度——里程碑验收、纠纷兜底
S5 复购合作过靠谱机构——再下单，信任沉淀
核心诉求
信任：怕被骗、怕被坑 → 要认证/口碑/担保
省心：不想线下反复比价扯皮 → 要标准化、线上闭环
透明：钱怎么花、进度怎么查 → 要托管可见、节点可见
② 合作方（卖方 · 服务提供者）
入驻的中介服务企业（金V）：资质代办、担保、造价咨询所、劳务派遣公司。平台的核心供给方。
核心场景
B1 入驻中介企业认证 → 缴保证金 → 发布服务
B2 经营管理"我的服务"——上架/编辑/下架，看曝光
B3 接单收托管订单 → 接单 → 按里程碑交付 → 结算
B4 收入看净收入、提现、保证金状态
核心诉求
订单来源：工程行业获客贵且难 → 要平台流量与转化
资金保障：怕收不到尾款 → 要托管结算不拖欠
经营效率：服务/线索/订单/收入一处管理
③ 平台（撮合者 · 规则制定者）
搭建双边市场，定规则、管资金、控质量。另有持牌托管机构承担资金监管。
商业目的
网络效应供给越多 → 用户越愿来；用户越多 → 服务商越愿入驻
收入阶梯佣金（commissionRate，用户侧隐藏）、保证金沉淀（三档：5000/2万/5万）
生态与招商/转让/人才并列的服务品类，形成工程服务闭环
平台规则抓手
资金托管：买方 available → 平台 escrow → 里程碑释放 → 结算净额
履约保障：4 节点里程碑（≥5 万启用）、14 天自动确认、未成交全额退款
治理：金V 认证、投诉响应、防跳单规则、纠纷仲裁
