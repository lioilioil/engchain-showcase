需求深化 · 01

R1主 Tabbar 不显示文字，切换时气泡提醒

按你的描述拆解为两层：常态——四个入口只保留图标，任何情况下不再显示常驻文字（含当前激活项）；切换反馈——点击任一 Tab 进入目标页面时，在 Tabbar 上方弹出目标页面名称的气泡，页面到达后自动消失。

关键决策

  • 气泡定位：水平居中于所点击 Tab 的图标，垂直位于 Tabbar 上缘上方，间距默认 12px（可调 8 / 12 / 16px，即“合理间距”）。
  • 气泡文案：“进入「发现」”——明确告知即将进入的页面名称。
  • 气泡材质：与 Tabbar 同族的玻璃胶囊（blur 22px + 半透明白/黑 + 顶部高光），可选小箭头指向所属 Tab。
  • 生命周期：点击即弹入（120ms）→ 贯穿页面过渡（300–900ms）→ 到达后停留 800ms → 淡出（250ms），全程约 1.6s，不常驻、不遮挡内容。
  • 跨页实现：点击时当前页弹一次；跳转后由 sessionStorage 携带目标名在新页再弹一次并自动消失，保证过渡不中断。
  • 边界：再点当前所在 Tab 不重复弹泡；气泡带 role="status" 供读屏播报。

交互时序

页面过渡保持 300–900ms

为什么这样设计：常驻文字移除后，气泡承担“我切到哪了”的即时确认；瞬时出现、自动消失，克制不打扰，符合减少干扰的导航反馈原则。

需求深化 · 02

R2压缩 Tabbar 宽度，删除玻璃块滑动动效

现状 Tabbar 占满屏幕宽度（flex:1），激活态靠独立玻璃块横向滑动指示（0.42s 弹跳曲线），还叠加了触摸横滑、鼠标拖拽两套手势。改版后：压缩为只容纳 4 个图标的紧凑胶囊，滑动块与全部手势逻辑一并删除。

关键决策

  • 尺寸：高 48px；4 槽 × 46px + 内边距 ≈ 200px 宽；图标保持 22px。
  • 触控：每个槽位 46×48px，满足 ≥44×44px 触控热区标准（修掉现状“激活前后热区不一致”的问题）。
  • 位置：在导航壳内居中，AI 信息工作台球保持在右端，二者间距 10px。
  • 动效：指示块切换无任何横向位移，仅原位浮现（scale 0.82→1 + 透明度，180ms）；彻底移除 click 滑动、touch 横滑、mousedown 拖拽、resize 重算。
  • 短屏适配：沿用 ≤720px 高度时 46px 的压缩规则。

为什么删除滑动手势

Tab 导航的语义是“点击即达”。玻璃块的弹跳曲线（cubic-bezier(.34,1.4,.64,1)）偏玩具感，与点击、拖拽并存的手势易产生误触；宽度压缩后 Tab 相邻更近，横滑误触概率更高。删除后交互更直接、可预期。

保留项：页面过渡的淡出/淡入与顶部进度条（pageTransition）不受影响；气泡提醒正好承接原“玻璃块滑动”的视觉反馈职责。
设计依据 · Accessibility：触控目标 ≥44×44pt设计依据 · Gestures：避免同元素叠加冲突手势
需求深化 · 03

R3激活图标变色 + 常规色块 · 两侧向内镜像（液态玻璃）

按你的两点要求合一：① 选中色块——一个常规色块，左右两侧向中心内凹，与主 Tabbar 两端外凸圆角互为镜像；② 材质——按下方开源案例重做液态玻璃：无固有色的半透明底 + 模糊吸色 + 上缘焦散高光 + 底部折射 + 内描边。图标浮于块上，激活时变色为主色。

向内镜像：块体侧面内凹曲率 = Tabbar 端部外凸曲率的镜像

液态玻璃材质分层（已按案例落地）

  • 底部投影（按案例重做）：选中块下方阴影为形状化投影层——对应 Coding Stella pill 投影（0 4px 12px + 0 1px 2px）与掘金外投影（0 8px 32px），改为同 clip-path 阴影层下移 + 模糊实现，随“向内镜像”形状走，落在 bar 内、不超出边界。
  • 透底：白色半透明渐变（无固有实色），透出 Tabbar 与背后的环境光。
  • 模糊：backdrop blur 16px + saturate 180% + brightness 1.06；用 clip-path 随形状裁切，模糊不溢出色块。
  • 上缘：白色 rim 高光（inset 0 2px 3px -1px）+ 顶部焦散亮纹（中间亮、两端淡）。
  • 底部：下缘折射（inset 0 -2px 4px -1px）+ 内侧反光 + 极淡主题色折射，营造“浸润感”。
  • 液态光泽层：顶部 46% 反射渐变 + 底部内侧亮线（掘金 .glass::after 技法）。
  • 着色克制：颜色只给图标（前景着色 --primary）；块体保持中性玻璃。
  • 边界约束：块体 34×37px，四周留 ≥5px，不超出 Tabbar 轮廓。
  • 明暗一致：暗色模式同一形状、同一材质逻辑——更低透明白 + 左右内侧暗影表现凹面，不用外凸白描边，避免“白色圆角胶囊”观感。
设计依据 · Liquid Glass：选中导航项用前景着色设计依据 · Color：颜色克制，勿让同一颜色承担多种含义
