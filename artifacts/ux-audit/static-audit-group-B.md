## 三、交易全链路体验分析

链路：**充值(recharge) → 余额/积分(wallet/credits) → 解锁(detail) → 下单(order/index+detail) → 托管/确认(order/detail) → 结算佣金(commission) → 提现(withdraw) → 发票(invoice)**

| 链路节点 | 摩擦点 | 级别 |
|---|---|---|
| ① 充值 | 无最低额校验（B-026）、未登录可充（B-027）、无破冰优惠锚点（B-028）、到账反馈弱（B-030） | E1–E2 |
| ② 买积分 | 微信/支付宝通道实扣余额（B-032）、默认选最低档（B-033）、余额展示含冻结（B-035） | E1–E2 |
| ③ 解锁 → 下单 | 订单列表无状态筛选（B-001），待支付订单容易漏掉 | E2 |
| ④ 订单详情 | **整页语法错误白屏（B-007）**；待支付无去支付按钮（B-008）；付款/退款 API 错用（B-009/B-010）；无里程碑时间线（B-011）；无佣金说明（B-012）；未付费明了电话（B-013） | **E0 + 多个 E1** |
| ⑤ 托管确认 | 资金托管说明仅 toast（B-020），无协议页；订单详情无"平台托管、未确认不打款"提示 | E2 |
| ⑥ 结算佣金 | 详情页费率/佣金不可见（B-012）；佣金流水需后台看，前台无入口 | E1 |
| ⑦ 提现 | 无银行卡管理（B-038）、pending 不可撤销（B-039）、无进度时间线（B-040） | E1–E2 |
| ⑧ 发票 | 专票税号不校验（B-043）、无企业认证门控（B-044）、催开票/下载是假按钮（B-045） | E1–E2 |

**链路最大断裂点**：第 ④ 步 order/detail.html 整页白屏（B-007），导致"下单 → 查看 → 支付 → 确认"主链路在第一步详情页就中断。这是 Group B 唯一 E0。
