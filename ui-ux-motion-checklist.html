视觉 / 交互 / 动效
检查目标书

把历史逐页打磨中反复出现的通用性问题，沉淀为可证伪、可验收的检查标准。每条含：检查目标、判定标准、历史问题来源、严重级。用于全量排查与交付前自检。

P0 阻断：功能/状态/跳转错误 P1 体验：可点但难懂/难用 P2 打磨：观感/对齐/文案

01视觉一致性检查目标

全 App 严格复用 V3.3 设计令牌，组件规格跨页统一，信息层级清晰，不出现孤立视觉。

V1 · 设计令牌零漂移P1
判定：颜色/字号/圆角/阴影全部走 --bg/--primary/--text-*/--r-*/--shadow-* 变量；grep 无散落硬编码色值（白字 on 金底除外）。
历史来源：profile/index 硬编码 #B58040 未走主色变量，已统一为 var(--primary)。
V2 · 组件规格跨页统一P1
判定：导航栏、卡片、按钮、标签 chip、开关、弹窗，同一角色在所有页面尺寸/圆角/间距一致；认证标签（蓝V）与等级标签（Lv.5）等高。
历史来源：认证标签与等级标签高度不一致；快捷工具缺"更多"入口。
V3 · 卡片长文本不撑高P1
判定：卡片内副文本（如"24 家·招完即止"、"云南/贵州/四川"）不得不合理换行撑高卡片；超长用省略号/渐隐/单行截断，保留关键信息，卡片标题除外。
历史来源：信息卡片不合理换行导致高度放大、效果不佳。
V4 · 首屏信息层级 3 层以内P1
判定：页面首屏主任务、主操作、辅助信息层级分明；不出现"大量卡片堆砌、主次不分、功能按钮与内容卡片混淆"；视觉焦点唯一。
历史来源：信息工作台卡片泛滥、视觉简陋、主次不鲜明，已整体重构。
V5 · 关键数字一眼可读P2
判定：金额/价格/进度/状态用大字重/字阶突出；单位、币种、百分比清晰；费率小数（0.2）必须显示为百分比整数（20%）而非原始小数。
历史来源：协议页意向金 0.2 被直接显示成"0.2%"，应显示"20%"。
V6 · 模块排序与视觉区分P2
判定：同一页内功能模块有清晰排序逻辑；功能相近模块（如等级横幅 vs 任务中心）视觉取向可区分，不混淆；用户信息头部不加重色块背景。
历史来源：个人中心模块排序调整；等级横幅与任务中心视觉不清；头部色块删除。
V7 · 营销位克制且插位合理P1
判定：营销卡片（限时优惠/0元入驻/5折）按规则插在内容流中合理位置，不堆在页面底部突兀插入、不遮挡主任务、不抢夺主操作视觉权重。
历史来源：营销卡片插在各页底部，不符合营销目的且突兀，已重写插入规则。
V8 · 无图区不浪费空间P2
判定：列表项无配图时，不保留重复占位 icon 区撑高行高；用紧凑文字行或结构化摘要替代。
历史来源：最近浏览列项上方多为重复 icon 区，浪费空间。
V9 · 导航标题唯一不重复P1
判定：导航栏标题与页面内 h1 大标题不同名重复；保留导航栏标题，页内用副标题/说明，不出现"我的发布/我的发布"两次。
历史来源：我的发布/草稿箱/已解锁线索三页导航与页内标题同名重复，已去重。

02交互体验检查目标

路径正确、状态不被反向修改、操作必有反馈、底部不遮挡、热区足够。

P0 红线 · 交互正确性：进入页面不得反向修改用户身份/状态；链接必须指向正确业务场景。以下 I1、I2 为一票否决项。
I1 · 身份/状态不被串改P0
判定：从 tabbar 进入"我的·个人中心"，不得把当前用户状态自动改成"注册会员"；必须延续进入前的身份状态（企业身份/建筑企业等），不做反向无操作修改。
历史来源：点"我的"直接把用户状态改为注册会员，已修根因。
I2 · 链接指向正确业务场景P0
判定："团队"链接在企业入驻身份下必须指向该企业的团队/成员管理页，不得跳分销中心；团队≠分销。每个入口链接指向其业务语义对应的页面。
历史来源：企业身份点"团队"进了分销中心，团队链接应对应企业团队页。
I3 · 页面可滚动P0
判定：内容超出一屏时页面可正常上下滚动；flex 高度链正确，不出现"页面无法滑动"死局。
历史来源：我的发布页无法上下滑动（flex 高度链问题），已修。
I4 · 底部固定栏不遮挡内容P0
判定：底部固定悬浮区（协议行+按钮行/吸底结算栏/底部操作按钮）高度 > 内容区底部留白；页面内容区 padding-bottom ≥ 固定栏高度，最末一条内容不被覆盖，可完整滚动显示。
历史来源：在线下单页底部按钮行+协议行遮挡内容；认证结果页底部按钮被遮，均已修。
I5 · 底部按钮文案精简P1
判定：主操作按钮文字简短动作明确；删除重复金额数据（如 ¥5000）、删除公司名称（如中建咨询），按钮只保留动作（如"确认选择并支付"）。
历史来源：在线下单按钮"确认选择...付意向金..."含重复金额与公司名，已精简。
I6 · 底部多按钮一行化P1
判定：结果页底部多按钮（如入驻成功三按钮）在一行内等分布局，不堆成竖排多块；按钮样式统一（参考分享页无背景悬浮按钮样式）。
历史来源：入驻成功页底部三按钮改一行；简历/资料/委托页底部按钮改无背景悬浮。
I7 · 返回 icon 大且清晰P1
判定：所有下级页面左上角返回 icon 尺寸足够大、清晰可辨，热区 ≥ 44×44px；不出现过小模糊返回箭头。
历史来源：所有下级页返回 icon 太小，已统一大尺寸 SVG。
I8 · 操作必有反馈与结果态P1
判定：点击主操作后有按压态/loading；提交后有成功/失败结果页或 toast；表单校验即时提示；不出现"点了没反应/不知成没成"。
历史来源：通用交互闭环要求。
I9 · 危险操作弱视觉、位置靠后P1
判定："退出登录"等危险操作弱化视觉（非主按钮色）、放在更深一级页面（如账号与安全下），不与普通设置项同级突出。
历史来源：设置页退出登录移到账号与安全页下方并弱化。
I10 · 空态/错误态/加载态齐备P2
判定：列表无数据时有插画+文案+引导按钮；加载时骨架屏；不出现白屏/半截内容/裸错误。

03动效与主题检查目标

动效克制服务状态反馈；主题一次渲染到位，不逐页闪烁。

M1 · 暗色主题无闪烁P0
判定：选择暗色主题后，所有页面直接按暗色渲染；不得先渲染明亮模式再切换成暗色（可见闪烁）。主题在页面加载最早期（head 同步脚本）读取并设定，不依赖渲染后再切换。
历史来源：暗色模式下每次切页先亮后暗闪烁，要求直接按选中模式加载。
M2 · 动效克制且有意义P1
判定：动效仅用于状态反馈（脉冲/进度）与转场；时长 ≤ 300ms；无炫技式动画；尊重 prefers-reduced-motion。
历史来源：信息工作台要求动效重构、主次鲜明。
M3 · 页面转场一致P2
判定：页面进入、弹层弹出、Tab 切换用同一套缓动曲线；不出现各页节奏不一。
M4 · 暗色对比度达标P1
判定：暗色模式下正文与背景对比度 ≥ 4.5:1；无白块/黑字丢失/反色异常；卡片层次用明度差区分而非纯黑堆砌。
历史来源：明暗双主题适配验证为全量排查必检项。
M5 · 长操作有进度反馈P2
判定：支付/上传/提交等长操作用户等待期间有进度或 loading，不静默卡住。
M6 · 滚动揭示不过度P2
判定：协议/长文页面滚动揭示仅用于章节区分，不强制遮挡内容；关键内容首屏可读，不依赖滚动才出现。

04一票否决红线

红线判定
身份状态被串改进入页面后用户身份/状态与进入前不一致（I1）
链接错业务场景入口指向与业务语义不符的页面（I2，如团队→分销）
页面不可滚动内容超出但无法滑动（I3）
底部遮挡主内容固定栏盖住末条关键内容/按钮（I4）
主题闪烁暗色页先亮后暗渲染（M1）
导航/页内标题重复同页标题出现两次（V9）
