01

一页结论与设计三决策

这不是"换皮红包弹窗"，而是一套在深色遮罩上由光效与漂浮物自行组织的异形（shapeless）惊喜时刻。所有执行围绕以下三条已拍板的决策展开，任何迭代不得回退。

决策一 动效

混合分层：高清透明 PNG 做主视觉，金币/星屑/光环用代码（CSS/JS）实时生成；锦鲤等重特效未来可用黑底 MP4 + mix-blend-mode:screen 增强，深遮罩下与透明等效。

决策二 主视觉

游戏化金色能量空投箱：同一科幻箱体贯穿闭合 / 开启 / 锦鲤三态，香槟金面板 + 深空灰装甲 + 冷青点缀，区别于市面大红红包，契合工程链 ToB 专业调性。

决策三 容器

零矩形：禁止任何完整矩形（含圆角卡片）。允许胶囊按钮、圆形关闭钮、非矩形光晕/丝带托底、文字描边与投影。

一句话边界

弹窗"骨架"（.wp-root / .wp-stage）永远透明——不承担背景、边框、圆角、投影；"底"只有毛玻璃深色遮罩。主视觉、文案、控件全部以漂浮元素分层落在遮罩上。

硬红线：页面里不允许出现任何用于"框住整组内容"的矩形面板，哪怕半透明、哪怕圆角 26px。控件本身的胶囊形与圆形不属于矩形卡片，是允许且推荐的。
02

竞品范式依据（可追溯，不编造）

结论全部来自公开行业资料与成熟产品实测，不凭空发明。原文链接见页脚。

2.1 弹窗分两类：面形与异形，我们选异形

人人都是产品经理《运营弹窗设计技巧》把弹窗外在表现概括为面形与异形两类：面形"通过背景色将内容圈定在一个比较规整的区域中"，常见红包、宝箱、礼盒；异形则摆脱规整背景，元素分散排布在遮罩层上。同刊《运营弹窗的设计要点拆解》与优设网文章都强调：弹窗是阻断感极强的模态视图，半透明蒙版负责隔绝内容层与浮出层——这恰好为异形特效提供了天然舞台。

  • 面形的代价：背景卡本身会抢占视觉重量，处理不当"反而增加信息量，影响核心信息传达"。拼多多签到/红包等成熟活动页实测即大量使用红色圆角矩形卡——转化直接但高度同质化，且与用户"禁止矩形、要高级感"的要求冲突，故仅作反面参照。
  • 异形的纪律：资料同时提醒异形需控制元素数量、防止散碎。因此本方案只用一个绝对主角（宝箱）+ 一条阅读动线，文案与控件沿中轴成组，光晕只做托底不做装饰堆砌。

2.2 最高级范式来自游戏开箱，而非电商红包

无卡异形最成熟的落地是游戏化开箱（如《和平精英》军需、《原神》祈愿）：统一语言为暗色全屏遮罩 + 发光宝箱 + 金色光柱 + 放射光芒 + 旋转能量环 + 飞出金币/卡面，标题与数值直接浮于画面，底部仅放一个胶囊主按钮。它满足三点：仪式感（用户主动开启）、视觉焦点唯一、CTA 不被容器干扰。本方案的三态视觉、放射光、能量环与金币喷射均沿用这套被亿级用户验证过的语法。

2.3 降低突兀感：用"中间层"与融合动效过渡

拼多多在红包链路中用礼包中间层作为过渡，配合融合动效降低弹窗直接砸脸的打断感。本方案对应做法：① 触发前可先出现 .wp-omen 预兆胶囊（呼吸微光）做预告；② 宝箱带轻微悬浮与光环入场，而非整块卡面淡入；③ 揭晓后才逐次浮出数值与 CTA，用时间编排分散注意力冲击。

2.4 主动曝光弹窗只留一个强 CTA、弱化关闭

运营弹窗通用转化原则（woshipm、Appcues 等多篇一致)：给明确利益的主动弹窗应聚焦单一主动作，关闭入口保留但不与主按钮争抢。本方案结果态只有一个金色胶囊 CTA，次级"先逛逛"降级为文字链接；圆形关闭钮保持可达但弱对比。

视觉是手段，转化与成本可控才是目的。每个设计决定背后对应一条可被运营验证的心理或风控机制。

机制在弹窗里的落点运营意图
沉没成本补偿触发条件是"长时间无有效动作浏览"，文案"逛了这么久"先共情，再给"补给"把用户的无效停留重估为"应得回馈"，降低流失、制造惊喜而非打扰
仪式感与掌控感用户必须主动点"轻触开启"才揭晓，宝箱开合 + 金币喷射主动参与提升禀赋效应与中奖体感，比直接发券记忆更深

04

视觉规范：零矩形硬规则与设计令牌

设计与走查时以本节为唯一裁判。任何新增元素先过"它是不是一个框住内容的矩形"这一问。

4.1 允许 / 禁止清单

允许 非矩形托底与控件
  • 胶囊形（border-radius:999px）按钮与标签
  • 正圆形关闭钮、能量环、光环
  • 非矩形光晕、放射光、光柱、丝带、气辉作为文字/主体的托底
  • 文字描边、多层投影、渐变字建立可读性
  • 透明主视觉 PNG 自带的不规则外形
  • 发丝级水平分隔线（不闭合、不成框）
禁止 任何矩形容器
  • 整块圆角卡片（含 26px 大圆角矩形）作为内容底板
  • 给标题/正文/成组文字统一套半透明矩形或"便签"底板
  • 满幅矩形场景图直接贴进矩形区块（旧 v2.0 做法）
  • 描边 + 渐变底 + 投影拼出的对话框式面板
  • 给每段小字机械套同款等尺寸气泡框
  • 大面积纯色矩形色块当背景分区

文字可读性不靠"加底板"，而靠描边 + 深色投影 + 背后局部光晕。仅徽章、有效期、CTA 这三类需要被点击或强识别的元素使用独立胶囊，且形态、大小要有层级差异，不批量复制。

4.2 主视觉三态（同一箱体，禁止换形象）

闭合态 sealed
gather · 悬浮 + 呼吸光环 + 轻触胶囊
开启态 open
微光 / 星意 · 金光柱 + 金币喷射
锦鲤态 lucky
粗光柱 + 放射光 + 金青能量环 + 金币雨
  • 三态必须是同一个科幻空投箱（装甲分件、香槟金面板、深空灰包角、圆形能量锁扣、信标灯、冷青点缀），仅在开合与光效强度上递进，避免用户认知跳戏。
  • 资产为透明底 PNG（由黑底母版本地泛洪去背得到），深遮罩下边缘干净；禁止再回退成满幅场景大图。
  • 揭晓后压缩主视觉高度（普通 250px / 锦鲤 292–350px），为金额、进度条、CTA 让出垂直空间，光效允许溢出但主体不被裁。

令牌值用途
遮罩底色深色墨蓝 + 毛玻璃隔绝内容层，是唯一的"底"；不使用纯黑，保留冷调层次

字体层级：主标题最大且加描边投影；副标题约为主标题 35%–55%；金额使用数字字体（DIN/Bahnschrift 栈）并做香槟金竖向渐变；同屏字体家族不超过两套。

四态文案与信息层级

文案由引擎上下文与奖励结果下发，弹窗只负责按态渲染。事实数字（积分数、98 解锁价、7 天有效期）不得手填，必须取数据。

状态主标题 / 副标题结果信息主 CTA（按身份）

实名：查看 / 使用
锦鲤 lucky补给已就位（带"今日锦鲤"徽章）68·88·98 积分；更强光柱/金环/金币雨；金额白金渐变同上，视觉权重最高

  • 有效期提示：游客为"已为你预留 7 天，注册领取后到账"（青调胶囊）；实名 credits 为"已到账 · 7 天内有效，可在钱包查看"。

  • 次级链接："先逛逛热门商机"，点击记 onDismiss('alt')，是低成本退路而非第二主按钮。
  • 措辞保持 ToB 专业、克制，不用夸张促销词、不用 emoji、不承诺数据之外的收益。
06

动效与素材：混合分层方案

原则：高清位图交给图片，矢量/粒子/光效交给代码，重特效在需要时才上视频。全部资源本地可离线运行，适配中国内地网络，不依赖境外地址。

6.1 为什么是混合分层

  1. 主视觉用透明 PNG：金属质感、复杂光影用位图最稳，三态各一张，切换即开合，无解码兼容问题。
  2. 金币 / 星屑 / 光环用代码生成：数量、方向、落点可按档位动态变化（普通金币少、锦鲤金币雨），体积零增量、可随 prefers-reduced-motion 一键关闭。
  3. 未来增强（lucky）用黑底 MP4 + screen：如需电影级光柱/粒子视频，导出黑底 MP4，容器加 mix-blend-mode:screen（滤色）——黑色被滤掉、光效保留，在本就深色的遮罩下与透明等效，是国内 H5 成熟兜底方案。

6.2 透明动效格式选型（结论先行）

格式透明能力 / 兼容体量本项目结论
Lottie矢量小动画、可全透明；复杂位图特效还原弱很小适合简单矢量图标/加载，不适合写实金属宝箱
APNG / 动图 WebP全 alpha、边缘光滑；浏览器支持好大（逐帧位图）短循环可用，长特效体积失控，非首选
WebM VP9 alpha唯一广泛支持 alpha 的网页视频；Safari/iOS 支持差小安卓/Chromium 可作增强，不能作唯一方案
黑底 MP4 + screen无 alpha 通道，靠滤色去黑；全端可播中推荐兜底：仅在深色遮罩下成立，正好匹配本弹窗
透明 PNG + CSS/JS全兼容、全透明、完全可控中等（已压缩去背）当前采用：三张主视觉 + 代码粒子

兼容性依据：WebM(VP9) 是唯一广泛支持 alpha 通道的网页视频，但 iOS/Safari 不支持或不稳定（SegmentFault 有跨浏览器实测）；因此跨端主路径不押注 VP9，而用 PNG+代码，视频仅作安卓端增强且必须 screen 去黑。

6.3 动效编排与性能

  • 时序：遮罩淡入 → 宝箱缩放上浮 + 光环 → 用户点击 → 切开启图 + 金币扇形喷射 + 光柱 → 金额 countUp（约 820ms）→ 档位/锚定/有效期依次浮入（delay .3s / .78s / .9s）→ CTA 最后到位并带呼吸光晕与扫光。
  • 金币 .wp-coin 与星屑 .wp-spark 由 JS 按扇形随机生成 transform/延迟；锦鲤档追加锥形放射光 .wp-rays、核心圆晕与白金光闪。
  • 只动画 transform / opacity，避免触发 layout；光效图层数克制，防止安卓中低端机合成器过载（实测连续重动画会显著抬高截图/渲染成本）。
  • 资源全部相对路径引用（CSS 内 ../assets/wonder/crate-*.png），规避全站 base 标签影响；三张图均需返回 200。

6.4 无障碍：减弱动效

在 @media (prefers-reduced-motion: reduce) 下：关闭粒子、光环、呼吸、扫光与入场动画，结果态直出；宝箱直接呈现对应态静态图。CTA 仍保留键盘焦点（揭晓后 btn.focus()），Esc / 点遮罩 / 关闭钮 / 预兆× 均可退出。

07

前端实现契约与已踩坑记录

业务时序在 js/wonder-engine.js（omen→gather→reveal→result），引擎只依赖全局 WonderPopup 的三个方法，DOM 结构与 class 可自由重构，但对外签名不得改。

7.1 文件与挂载

  • css/wonder-popup.css、js/wonder-popup.js：v3.0 无容器异形版；资产 assets/wonder/crate-{sealed,open,lucky}.png。
  • 挂载自适应：页面存在 .phone（实验室壳）时挂其内部并 absolute；真实 App 页面无 .phone，挂 document.body 并加 .wp-fixed，fixed 全屏、z-index 1200。
  • 底部留 calc(92px + env(safe-area-inset-bottom))，适配全面屏安全区。

7.2 对外 API（唯一契约，勿改签名）

window.WonderPopup.show(ctx)   // 打开；ctx 由引擎组装
window.WonderPopup.close()     // 关闭（含 0.3s 离场后移除节点）
window.WonderPopup.isOpen()    // boolean

// ctx 关键字段
{
  decisionId, persona, guest, budgetState,      // 'normal' | 'warning' | 'exhausted'
  unlockPrice, balance, topLabel,
  nba: { ctaText, ctaHref, altText, altHref, postTitle },
  onReveal(),                 // -> {kind:'credits'|'pending'|'none', amount, tier, tierLabel, expireAt}
  onCta(result),              // 主按钮
  onDismiss(phase)            // 'close' | 'scrim' | 'esc' | 'alt' ...
}

7.3 状态机

  1. omen 预兆（可选）呼吸胶囊预告，降低突兀感，可被 × 关闭
  2. gather 待开启闭合箱 + 轻触胶囊；熔断态在此 780ms 后自动揭晓，不让开空盒
  3. reveal 揭晓切开启图、粒子、光柱、金额滚动；class 切到 .wp-revealed
  4. result 收口补全标题/档位/锚定/有效期，CTA 聚焦；class 加 .wp-phase-result

7.4 已踩过的坑（务必规避）

坑 1 · 渐变字在 flex 父级失效

把 background-clip:text 写在 display:flex 的容器上，Chrome 不会把背景裁剪到子 span，结果文字透明、只剩灰色 text-shadow。渐变必须直接写在含文字的 .wp-amount-num / -unit 上，父级只做布局。

坑 2 · display:none 期间动画空转

待揭晓元素若在 gather 期 display:none，其入场动画在隐藏期就开始计时，揭晓后表现为"迟迟不出现"。改为未揭晓才 none、一旦 .wp-revealed 立即恢复 display，动画从揭晓时刻起算。

坑 3 · span 默认 inline 尺寸失效

.wp-tap-ring 是 span，漏写 display:block 时 138×48 不生效、轻触胶囊不可见。自定义尺寸的 span 必须显式 block / flex。

坑 4 · 强缓存拿旧 CSS

新 DOM 类名配旧样式会出现"仍是闭合箱/元素缺失"的假象。发版需给 CSS 加版本号或让缓存策略失效后再回归。

不要在金额元素上加 filter:drop-shadow：它与 background-clip:text 叠加会让渐变字透明。金额辉光改用文字自身渐变与父级光晕实现。
