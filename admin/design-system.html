1. 设计原则

shadcn 中性风
中性 slate 色调，无品牌彩色。唯一彩色 = destructive 红 + 图表五色。功能语义色去饱和，仅用于状态标识。
8px 网格
所有间距、尺寸基于 4/8px 倍数。space-1=4px 至 space-8=32px，组件高度 32/36/40px 三档。
极克制动效
仅 hover/fade/translate，时长 150-200ms，ease-out 缓动。全局尊重 prefers-reduced-motion。
tabular-nums
所有数字使用等宽表格数字，金额、数量、页码对齐不跳动。.num / .an / .amt 类自动启用。

12. Tabs

这是「概览」标签页内容。Tabs 组件使用底部 2px 指示条，active 时 primary 色，区别于 .seg 分段控件。
这是「详情」标签页内容。点击不同标签切换显示对应 .tab-panel，带 fade-in 动画。
这是「设置」标签页内容。Admin.Tabs.init(container) 自动绑定所有 .tab 按钮与 .tab-panel。支持键盘 ← → 切换、Home/End 跳转，含 role="tablist"/aria-selected 等 ARIA 属性。

13. Drawer

Drawer 支持右侧（默认）/ 左侧变体，宽度默认 480px 最大 90vw。ESC / 遮罩点击 / 关闭按钮均可关闭。已补齐焦点陷阱（Tab 循环）、背景滚动锁定、ARIA role="dialog"、z-index 堆叠管理，CSS 类驱动 slide 动画。

14. Modal / Dialog

Admin.Modal 用于复杂表单/自定义内容场景（独立 .modal-overlay/.modal-dialog 类名，含焦点陷阱/动效/ARIA/滚动锁定/z-index）；confirmDialog 用于简单确认操作（API 向后兼容，新增 Escape/Enter/焦点陷阱/loading 防重复/动效）。

15. Toast

Toast 支持 ok/err/info 类型样式，多条垂直堆叠，3 秒自动消失，可点击 × 手动关闭。
