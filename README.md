# 工程链 ENGCHAIN · 高保真交互原型

> 建筑行业 · 用户自主驱动型供需匹配工具 · AI 全链路赋能
> 纯 HTML5 + CSS3 + 原生 JS(ES6+)，无框架，iPhone 真机框架内逐页跳转。

---

## 一、项目定位

**工程链 ENGCHAIN** 面向建筑工程行业，帮助**需方**（找物资/劳务/设备）与**供方**（供应物资/劳务/设备）进行**信息发布、AI 匹配、沟通对接、付费解锁、认证入驻与分销**，形成完整的供需撮合闭环。

- **用户自主驱动**：用户自行发布、搜索、筛选，AI 提供补全与匹配，而非 AI 主导决策。
- **AI 赋能**：AI 一句话补全表单、AI 自然语言搜索、AI 智能匹配百分比、AI 推荐文件夹。
- **信息碎片化遮挡付费墙**：公司/联系人/电话/微信/地址/文件 6 类关键信息默认模糊遮挡，付费后依次揭示。

## 二、使用方式

直接通过浏览器打开（无需构建）：

- **总览演示**：`preview.html` —— 单台 iPhone 真机外壳 + 左侧全页面导航 + 演示状态控制台。任意页面通过导航加载进这台唯一外壳，可观察全部交互；控制台通过 **localStorage** 持久化「身份(需方/供方) / 主题(明/暗) / 会员 / 账号」，模拟已登录用户与应用状态切换。
- **单页入口**：`index.html` —— 工作台主页（对齐参考 Home：眉标 / 轮播 / 搜索 / 特色卡 / 推荐职位 / 工程项目 / 悬浮玻璃底栏）。
- 每页可在预览中实际交互，页间跳转为真实路由。

> 建议以 `preview.html` 作为演示起点。

## 三、技术栈与架构

| 层 | 说明 | 文件 |
|----|------|------|
| 设计系统 | 设计令牌(V3.3 Editorial×Industrial · 暖米#F4F2EE + 古铜金#C9A961，明/暗双主题) + 通用组件 | `css/app.css` |
| iPhone 真机壳 | 钛金属边框 / 灵动岛 / 侧键 | `css/iphone-frame.css` |
| Mock 数据层 | 供需、会话、钱包、分销、推荐数据（统一目录 `catalog` + 业务场景 `bizKey`/`dir` 打标） | `js/data.js` |
| 通用脚本层 | Toast / 半屏Sheet / 居中Dialog / 返回 / 状态栏注入 / 证书卡 / 支付墙 | `js/common.js` |
| 单一详情引擎 | 7 大业务场景按 `bizKey` 分发 hero/正文/解锁/操作栏 | `js/detail.js` |
| 页面 | 10 大模块共 41 个页面 | `pages/**` |

**页面模板约定**：每个页面是一个 `.phone` 容器（390×844 屏幕），进入后由 `common.js` 自动注入状态栏与灵动岛；页面脚本首行设置 `window.__ROOT__`。

## 四、核心闭环

```
注册/登录 → 发布(双身份) → AI 一句话补全 → 浏览/搜索(自然语言) → AI 匹配% → 沟通 → 付费解锁联系方式 → 认证入驻 → 分销赚钱
```

对应模块：`auth → publish → supply/list/search → message → supply/detail(付费墙) → profile/auth → distribution`。

## 六、设计语言（V3.3）

- **风格**：Editorial × Industrial，明色为主 + 暗色主题。对齐 `design-system-demo-fixed.html` 的 5 套高保真原型。
- **底**：`#F4F2EE` 暖米白，衬古铜金微光晕。
- **主色**：`#C9A961` 古铜金（信任/专业/品质），辅以需求蓝 `#2563EB`、成功绿 `#2B6B4F`、错误红 `#B3261E`、会员金。
- **字体**：中文 `PingFang SC`，英文/数字 `Barlow`（工程感），金额/编码用等宽。
- **组件**：玻璃拟态卡片、毛玻璃导航、灵动岛、支付墙模糊揭示、AI 脉冲/文件夹、3 层阴影、极细线。

## 八、Vibe Coding 说明

本原型为一次性高保真交付，`data.js` 为 Mock 数据层，后续接入真实业务时仅需替换该层及对应接口。视觉与交互已整体换肤为 V3.3（暖米 + 古铜金 + Barlow），历史参考文件中的交互/视觉问题未沿用。
